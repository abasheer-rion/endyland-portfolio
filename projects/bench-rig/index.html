Automated bench test rig

Python scripts that drive a function generator and an oscilloscope over SCPI. A 12-point amplifier test went from 45 minutes to 90 seconds.

2026. Python and SCPI.

45 minutes to 90 seconds

Testing an amplifier by hand means setting a signal on the function generator, reading the result on the oscilloscope, writing it down, and repeating for every test point. A 12-point test took 45 minutes, and it is easy to misread a number or skip a step.

The script does the same test in 90 seconds, which is 30 times faster. It also caught a 3 dB error that manual checks had missed.

How a run works

Most bench instruments accept text commands over a standard called SCPI. Two of its common commands are *IDN?, which asks an instrument to identify itself, and *RST, which puts it back in a known state. Each maker adds its own commands for its own settings, so the script has a small set of instrument-specific calls on top of the standard ones.

A run has four steps. The script sets up the instruments, sweeps the 12 test points, draws charts of the result, and flags anything that looks wrong. The charts are drawn at the end of the run, so the whole result is visible at once.

  1. Set upReset both instruments and set the ranges.
  2. SweepStep through the 12 test points and read the scope at each.
  3. ChartDraw the results.
  4. FlagMark readings that look wrong.
