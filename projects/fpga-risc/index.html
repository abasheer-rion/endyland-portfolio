8-bit RISC processor on FPGA

An 8-bit processor with a five-stage pipeline and 16 instructions, written in Verilog and run at 50 MHz on a Xilinx Artix-7.

2026. Verilog and Vivado.

Five stages

A processor fetches an instruction, decodes it, executes it, reads or writes memory if the instruction needs that, and writes the result back. In this design each of those is a stage, with a register between each pair of stages. Five instructions can be in flight at once. That arrangement is a pipeline.

The datapath is 8 bits wide and the instruction set has 16 instructions. The design is written in Verilog and built with Vivado.

  1. FetchReads the next instruction from instruction memory and advances the program counter. 
  2. DecodeTurns the instruction into control signals and reads the registers it names. 
  3. ExecuteDoes the arithmetic or logic in the 8-bit ALU. 
  4. MemoryReads or writes data memory when the instruction needs it. 
  5. Write backSelects the result and writes it to the register file. 

Clock cycle 1

Cycle12345678

Every pipeline register loads on the same clock edge, so on each tick every instruction moves one stage on. Instruction 1 takes five cycles. Instruction 2 starts one cycle after it, instruction 3 one cycle after that. From cycle 5 on, one instruction finishes on every tick, which at 50 MHz is up to 50 million instructions a second.

The slowest path

The clock cannot run faster than the slowest stretch of logic between two registers. The target on the Artix-7 was 50 MHz, a 20 ns period. I used Vivado’s timing report to find the slowest path, changed that logic and ran the tools again. The slowest path ended up 22% shorter than before.
