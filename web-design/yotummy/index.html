YoTummy

A marketplace for homemade food from local cooks, with a website, a seller portal, an admin panel and a phone app.

Only developer, June 2026 to now. Angular, Ionic, PHP, MySQL and Stripe.

  • yotummy.com

What it is

YoTummy lets people buy homemade food from cooks and farmstands near them. Shoppers use the website or the phone app. Cooks list food in the seller portal. The owners run the marketplace from the admin panel.

The marketplace already had sellers and shoppers when I took over its code. The web apps are Angular 12 on a PHP 7.4 and MySQL backend, with Stripe for payments. The phone app is Angular 18 with Ionic and Capacitor, so one codebase goes to both app stores. The front ends are hosted on Vercel and the backend on Hostinger.

What I did

  • Fixed payment recording so real Stripe payments are still saved while the webhook secret is missing.
  • Built the map of nearby sellers. Pins load first, and on phones a pinch zooms the map instead of the page.
  • Rebuilt sections of the web home page and reworked in-app messaging: timestamps, a full-width seller chat and a badge that clears.
  • Set up automatic deploys for the backend and the front ends, including a check that stops a failed database migration from running again.
  • Prepared app version 3.1.1 for Android and iOS.
  • Built a separate Next.js prototype with a Mapbox map of seller photos and a category showcase, to propose a redesign to the founder.
