endyland.com

This portfolio: a home page, six section pages and a page for each project, in plain HTML, CSS and JavaScript.

Design and code, October 2026 to now. Hosted on Cloudflare Pages. three.js for the 3D parts.

  • Code on GitHub

How it is built

There is no build step. The files in the repository are served as they are. The top bar, footer, type scale and project layout live in a few shared files, and each section and each branded project page adds its own look on top.

The security policy allows scripts only from this site and no inline scripts. A check script runs on every push and fails on a broken local link, an inline script, an image without a size, a photo over 200 KB or a loosened security policy. A push to the main branch deploys to Cloudflare Pages. A pull request only runs the checks.

3D models

The 3D parts are drawn with three.js, vendored in the repository so the site makes no request to another host. Each model is one JavaScript file. The model below is the four-element 5.8 GHz patch antenna array from the research page. Dragging turns it, and the beam sweeps from side to side.

What I did

  • Designed and built the whole site in plain HTML, CSS and JavaScript.
  • Gave each section its own look, and let each branded project page use its client’s colors and fonts.
  • Built the shared top bar, footer and project layout.
  • Built the 3D model viewer and the models on the home and project pages.
  • Wrote the check script and the deploy workflow.
