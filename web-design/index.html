Web design

Sites and apps I designed and built, for clients and for myself.

Six projects: a food marketplace with a phone app, a land investment firm, a car detailer, a mango shop, a software company and this site. Each one has its own page with the problem, how it works, the numbers and what I learned.

How I build a client site

I start with the one thing a visitor has to do: order food, book a detail, ask about a property. Everything on the page either leads to that or gets cut.

Then I build the smallest version that does it. Detail Theory is one hand-written page and two small server handlers. New Door’s inventory site is one static file that reads a Google Sheet. Small things are easy to hand over and easy to fix.

Clients already have tools they trust, so I connect to them instead of replacing them. Bookings go to Google Calendar. Leads go to the CRM. Payments stay in Stripe and Shopify.

After launch I keep the repository, the deploys and the checks in order, so the next change is as easy as the first.
