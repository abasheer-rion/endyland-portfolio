Detail Theory

A one-page website with online booking for a mobile car detailer in Dallas-Fort Worth.

One of two developers, May to October 2026. Plain HTML, CSS and JavaScript on Vercel, with Google Calendar and Google Places.

  • detail-theory.com

What it is

Detail Theory details cars at the customer’s address: hand detailing, ceramic coatings and paint correction. The owner wanted bookings to come through the site.

The site is one HTML file with no framework and no build step, plus two small server functions. The booking form has steps, so each screen asks for a little. A reviews strip shows the business’s Google rating and reviews.

How a booking reaches the calendar

The relay sits between the page and the Google script because the script sends no CORS headers, so the browser cannot call it directly, and because the shared secret must not ship to the browser. The reviews function works the same way: it asks Google Places for the rating and review text, and the Google key stays a server secret.

What I did

  • Built the one-page site by hand, without a framework.
  • Built the step-by-step booking form and the relay that puts each booking on the business calendar, with the address in the event location and the customer as a guest when they give an email.
  • Built the reviews strip that reads the rating from Google Places.
