RION Solutions website

A rebuild of the RION Solutions company website in Next.js. The live site still runs the Framer version.

Main developer, April 2026. Next.js, Tailwind and Framer Motion.

  • rionsolution.com

What it is

RION Solutions builds automation software. Its website was made in Framer. I rebuilt it in Next.js so it lives in a git repository, and changes go through pull requests like the rest of the company’s code.

Styling moved from settings in the design tool to Tailwind classes. The motion the Framer site had is written with Framer Motion. The page keeps the look of the original: a dark starfield with a red glow, a headline about scalable automation, a Book a call button and the product sections, including the custom AI development offer.

What I did

  • Rebuilt the Framer site in Next.js with Tailwind and Framer Motion.
  • Matched the live site’s starfield, red glow and product sections.
