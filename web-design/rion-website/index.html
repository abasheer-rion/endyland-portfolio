The problem

A company site that needed to be code in a repository, not a page in a design tool.

RION Solutions builds automation software. Its site was made in Framer. That is quick to start, but the team could not review changes like code, reuse components with the rest of the product work, or control how it was built and hosted.

Approach

Rebuild the same look and content in Next.js, so the site lives in git next to everything else the company ships.

  • Next.js for pages and routing.
  • Tailwind for styling, so the design tokens live in one place.
  • Framer Motion to keep the motion the Framer site had.

  • A rebuild is easy to start and hard to finish. Content, motion and small details decide whether it feels like the original.
  • Writing down what is live and what is not keeps a portfolio honest.
