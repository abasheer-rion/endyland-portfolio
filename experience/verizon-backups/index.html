Voice network device backups

Found 200+ live voice-network devices set to keep no backups, automated the backups and handed the rollout to operations.

Verizon internship, 2025 and 2026. Python and SSH.

The problem

Live voice-network devices were set to keep no backups. If a device failed, there was nothing recent to restore from. I found 200+ devices in that state.

What I did

  1. Wrote Python automation that takes the backups over SSH and the devices’ own command line, so they run without anyone starting them.
  2. Ran it unattended for 3+ days on 4 nodes, then restored from those backups to confirm they worked.
  3. Found a firmware dependency while configuring the devices. It meant the planned rollout was not supported, and I stopped it before it went out.
  4. Wrote a requirements spec of 25+ items and handed the work to operations.
