Data project

Public spending data explorer

A search tool for county spending records. The records were messy, so most of the work was cleaning them until one question could get one answer.

Dates
2026
Stack
  • Python
  • Data pipeline
  • No public link.

By the numbers

  • 250K+rows cleaned
  • 40+duplicate vendors merged
  • 20 minper search before
  • Under 5 sper search now

The problem

Public records are public, and still hard to use.

County spending comes as a long list of payments. The same vendor shows up under several spellings, so asking “how much did we pay this company?” means hunting for every variant by hand. Each question took about 20 minutes.

The goal was a search that gives one answer per question, fast enough to ask follow-ups.

How it works

  1. Start with the raw rows250K+ rows of county spending records.
  2. CleanMake the rows comparable so they can be searched and added up.
  3. Merge vendors40+ vendors appeared under more than one name. Each now has one.
  4. SearchA question that took 20 minutes by hand takes under 5 seconds.
