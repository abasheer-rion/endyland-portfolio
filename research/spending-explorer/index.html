Public spending data explorer

A search tool for county spending records. It cleans 250K+ rows and merges 40+ vendors that appear under several names. A search that took about 20 minutes by hand takes under 5 seconds.

2026. Python.

One vendor, many spellings

County spending comes as a long list of payments. The same vendor appears under several spellings, so asking how much was paid to one company meant looking for every variant by hand. The tool cleans the rows so they can be added up and gives each vendor one name.

The table shows three sample vendors with amounts invented for this page. Merging folds the spellings into one row with the total.
